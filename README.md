# 🤖 CodeAlpha Basic Chatbot

A simple rule-based chatbot developed using Python as part of the CodeAlpha Python Programming Internship.

[![Follow me on GitHub](https://img.shields.io/github/followers/Seshan24?label=Follow%20me%20on%20GitHub&style=social)](https://github.com/Seshan24)

## Features

- Interactive conversation
- Greeting responses
- "How are you?" response
- Bot identity response
- Help command
- Exit command
- Continuous conversation loop

## Supported Commands

```
You: hello
Bot: Hi! 👋 Nice to meet you!

You: how are you
Bot: I'm fine, thanks! 😊 How are you?

You: what is your name
Bot: I'm CodeBot, a simple Python chatbot. 🤖

You: bye
Bot: Goodbye! 👋 Have a great day!
```
